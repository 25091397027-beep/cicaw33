Tipografi: Playfair Display (600/Italic) untuk judul emosional & bab cerita; Inter (400–700) untuk dialog, indikator, dan HUD dengan kontras tinggi.

2. Pencahayaan, Proporsi & Rasio Aset

  • Skala Dunia 3D: 1 unit Three.js = 1 meter. Rizka = 1.61 unit, Kael = 1.77 unit, pintu apartemen = 1.05m × 2.15m.
  • Pencahayaan Chapter 2: Menggunakan kontras Cool Corridor Ambient (#A8C2DF) melawan Warm Interior & Morning Sun (#FFE6BA / #F4C57A), dengan bayangan lembut PCFSoftShadowMap.
  • Tekstur Prosedural: Canvas 2D 128×128 (iris mata anime), 256×256 (lantai teraso koridor, serat kayu meja/pintu, plaids), dan sprite uap minuman 64×64.

3. Daftar Aset Visual Berhasil Dibuat vs Belum Tersedia

Tersedia & Aktif di Browser:

• Chapter2WorldBuilder: Set 3D Unit 302 (Kamar Rizka), Koridor Apartemen Lt. 3 (Pintu 302 & 301 bersebelahan), dan Unit 301 (Interior Apartemen Kael + Meja & Cangkir Hangat).
• CharacterFactory: Single Master 3D Model Rizka & Kael dengan swap kostum (Uniform/Casual/Home), rambut, ekspresi wajah 3D, dan properti payung.
• Chapter2SceneDirector: 5 preset kamera & komposisi sinematik (Scene A–E) + dialog preview.
• UI/UX Kit: Main Menu, HUD adaptif, Dialogue Box, Loading/Transition Overlay, Pause, Settings (termasuk pengaturan kontrol HP), dan Modal Konfirmasi.

Belum Tersedia (Menunggu Kebutuhan Lanjutan):

• Ilustrasi 2D CG full-screen resolusi cetak (saat ini menggunakan render 3D sinematik real-time & vector SVG reference sheet).
• Rig animasi tulang penuh (GLTF/FBX eksternal) — saat ini menggunakan hierarchical pivot rig Three.js prosedural yang ringan dan bebas dependensi eksternal.

4. Kontrak Integrasi untuk Programmer Gameplay

Seluruh komponen presentasi dipisahkan di dalam namespace global window.CicawwVisualAPI agar programmer gameplay dapat menghubungkan state, quest, collision, dan input tanpa menulis ulang UI atau aset 3D:

• CicawwVisualAPI.applyScenePreset(sceneId) // 'ch2_scene_a' .. 'ch2_scene_e' | 'ch1_courtyard'
• CicawwVisualAPI.setCharacterState(charId, { outfit, hair, expression, mode })
• CicawwVisualAPI.setLightingPreset(presetId) // 'warm_morning' | 'corridor_daylight' | 'warm_interior' | 'rainy_afternoon'
• CicawwVisualAPI.showDialogue(dialogueId) / CicawwVisualAPI.showNotification(msg, type)
• CicawwVisualAPI.showConfirm({ title, message, onConfirm })

Cara Menjalankan Preview: Buka file cicaww33_chapter2_visual_layer.html langsung di browser modern (Chrome/Edge/Safari/Mobile), lalu klik Preview Chapter 2: Next Door di Main Menu dan gunakan tombol Scenes di kanan atas HUD untuk berpindah antar Scene A–E.
